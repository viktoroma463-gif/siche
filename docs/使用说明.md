# 思拆使用说明

这份说明按「你做什么 → 系统怎么响应 → 你看到什么」来写。第一次用，照着第 0 节走一遍即可。

---

## 0. 一分钟上手

1. 打开页面，先看到 3 秒「思拆」闪屏，不用点击。
2. 自动进入主界面：左边是思想留存 / 规划单 / 风险清单，右边是协作区。
3. 在右侧顶部选一个模块，或者不选（默认通用思辨）。
4. 在底部输入框写下你的**草稿、判断、理由或困惑**，点发送。
5. 思拆会针对你这段话分析，并给出下一步问题。
6. 如果你想把 AI 的分析复制走，点 AI 消息右下角的「复制」。
7. 如果是「引导」类内容，直接复制；如果是「支架」或「AI参考草稿」，会先弹出一个 80–300 字的批判性微测试。

## 3. 五个模块分别干什么

| 模块 | 适合什么时候点 | 你可以这样写 | 思拆会怎么回 |
|---|---|---|---|
| 确定研究问题 | 题目太大、变量不清、不知道能不能做 | 「我想研究手机通知对学习的影响，但不知道问题是不是太大」 | 帮你区分话题与研究问题，追问变量、边界、可行性 |
| 文献线索与检索 | 手里有几篇文献但不会归类、找不到缺口 | 「我有三篇通知干扰的论文，不知道怎么归类写综述」 | 引导你做文献编码、找共识/争议/空白，给检索词思路 |
| 核心观点探讨 | 有想法但站不住、怕被反驳 | 「我认为通知频率越高专注越短，因为注意力会被反复拉回」 | 拆主论点/子论点，检查可证性，引入反方视角 |
| 证据评判 | 有数据/文献但不知道够不够 | 「这三篇实验样本都只有二十人，能支撑结论吗」 | 区分证据类型，提示样本、测量、边界条件 |
| 论证逻辑检查 | 段落读着顺但总觉得哪里不对 | 「帮我看看这段从前提推到结论有没有跳步」 | 检查推理链条，找循环论证、因果混淆、缺链 |

**不选模块**：默认「通用学术思辨」，适合概念解释、自由讨论。

**取消选择**：再次点击已经选中的模块，就会回到通用视角。

## 4. 你做什么，会触发什么

| 你的操作 / 说法 | 系统触发 | 你看到什么 |
|---|---|---|
| 直接写自己的判断、草稿、困惑 | 正常分析 | 一条「引导」消息，可直接复制 |
| 点选模块 | 切换分析视角 | 后续回复换视角；历史对话不清空 |
| 说「直接帮我写」「不会做」「帮我决定」 | 第一层引导 | 2–4 个思考角度 + 反问，不给成品 |
| 继续说「还是不会，直接写」 | 第二层引导 | 空白句式支架，用【】占位 |
| 第三次继续说「帮我写完整」 | 第三层引导 | 一个标注【仅思路示范，禁止直接复用】的局部小片段 |
| 第四次仍坚持 | 停止给支架 | 只给「缩小问题 / 保存进度退出」两个按钮 |
| 写出自己的想法，并说「帮我整理成参考草稿片段」 | 草稿四项条件校验 | 满足则生成「AI参考草稿」，左侧风险清单闪 2 秒 |
| 点 AI 消息下方的「复制」 | 复制审查 | 引导类直接复制；支架/草稿弹微测试 |
| 点「研究规划单」 | 打开侧边抽屉 | 4 个编辑框，只覆盖左侧，不挡右侧聊天 |
| 点「从对话提取思考预填充」 | 提取你的发言 | 自动填入 4 个栏目；已有内容会先确认是否追加 |
| 点「导出会话档案」 | 导出 | 下载 HTML + JSON 两份文件 |
| 点「新任务」 | 新建会话 | 规划单清空，开始新记录 |

## 5. 三种 AI 消息，怎么认，怎么复制

| 消息右上角标签 | 含义 | 复制行为 |
|---|---|---|
| 引导 | 概念解释、角度、反问、分析 | 点「复制」直接复制，无弹窗 |
| 支架 | 句式支架、要点清单、局部示范 | 点「复制 · 需审查」，弹微测试 |
| AI参考草稿 | 满足四项条件后生成的草稿 / 润色参考 | 点「复制 · 强制审查」，必须完成微测试 |

复制按钮在每条 AI 消息的**右下角**。

## 6. 复制与批判性微测试

1. 点 AI 消息右下角「复制」。
2. 如果是「引导」：直接写入剪贴板，提示「已复制」。
3. 如果是「支架」或「AI参考草稿」：
   - 弹出局限声明：本内容为认知辅助支架，不可以直接粘贴进作业/论文；截图无法规避该机制，本设计目的唤起自主反思。
   - 选择一项：
     - 接受并微调
     - 补充对立思考
     - 指出适用边界
   - 写 80–300 字，点「提交辨析并申请解锁」。
4. 提交后：
   - 通过字数校验 → 解锁本条复制，并自动复制。
   - 不足 80 字或超过 300 字 → 提示字数，保持锁定。
5. 点「暂不测试，保持锁定」→ 关闭弹窗，本条仍不可复制，但文字可以正常阅读。

**注意**：

- 微测试不校验对错，敷衍内容也会原样保存和导出，交给老师评估反思质量。
- 你的作答会保存在会话记录里（SQLite），导出时一并输出。
- 浏览器手动选中复制、截图无法被程序记录。

## 7. 什么时候会生成「AI参考草稿」

必须同时满足四项：

1. **你已经写出自己的想法**：草稿、个人判断、推理、取舍倾向；多轮自己修改后的稿子也算。
2. **完成一轮思辨来回**：思拆已经给过角度/反问，你又给出了自己的反馈；只回「好的、明白了」不算。
3. **你明确请求**：参考片段、改写、整理、润色类写作素材。
4. **不是整篇论文或完整大章节**：只生成局部片段。

### 一个完整例子

第一轮你写：

> 我认为通知频率越高，连续学习时段的专注时长越短，因为注意力会被反复拉回。

思拆会分析你的因果链，指出中介变量、证据缺口。这是「引导」。

第二轮你写：

> 我的想法是：通知频率越高，注意力被拉回次数越多，连续阅读时长就越短；请根据这段想法，帮我整理成参考草稿片段。

此时四项条件满足，生成「AI参考草稿」。开头会出现：

> 【⚠️以下为AI参考草稿素材，仅用于写作参照，不能直接复制提交作业，需要你结合自身研究重新改写】

末尾会出现：

> ⚠️已生成AI参考草稿，请查阅左侧风险审查清单开展自我核查

左侧风险审查清单会闪 2 秒浅砖红色。

### 不满足时会怎样

- 只贴外部资料、没有自己的判断 → 继续引导。
- 只回「好的」→ 不算一轮思辨来回。
- 只说「帮我写」→ 走四层引导，不给草稿。
- 要「整篇论文 / 完整章节」→ 拒绝，只给局部。

### 特殊润色

如果你已经根据建议提交了两轮以上自己修改后的草稿，再明确提出「帮我润色成参考版本」，可以生成润色类「AI参考草稿」，同样强制微测试。

## 8. 四层引导：被拦住了怎么办

| 第几层 | 你会看到 | 你该做什么 |
|---|---|---|
| 第一层 | 2–4 个角度 + 反问 | 选一个角度，写下自己的判断 |
| 第二层 | 空白句式支架（【】占位） | 用自己的话补全一两处 |
| 第三层 | 局部小片段，标注【仅思路示范，禁止直接复用】 | 不要照抄，改写成自己的版本 |
| 第四层 | 只剩「缩小问题 / 保存进度退出」 | 缩小问题，或写下想法后再请求草稿 |

**最快的解法**：不要继续说「帮我写」，而是写下你自己的判断或草稿，再请求「根据我的想法整理成参考片段」。

## 9. 个人思想留存区

- 你在右侧输入框发送的**每一条内容**都会自动出现在这里。
- 固定高度，内容多了在区块内部滚动，不会把页面撑坏。
- 每条带时间戳，纯文本显示，不渲染 Markdown。
- 关闭页面重新打开，记录仍在。
- 这里只存你的发言，不存 AI 回复。

## 10. 研究规划单

1. 点击左栏「研究规划单」→ 从左侧滑出抽屉。
2. 抽屉只覆盖左侧，右侧聊天仍可正常发送消息。
3. 四个固定栏目：
   - 我的问题
   - 当前已有的证据
   - 尚存疑点 / 待思考
   - 下一步打算做什么
4. 输入框失去焦点自动保存；也可以点底部「保存」。
5. 「从对话提取思考预填充」：
   - 只提取你的发言，不提取 AI 回复。
   - 如果规划单已有内容，会弹确认：「规划单已有内容，预填充将会追加到现有内容末尾，是否继续？」
   - 预填充只是草稿，可以自由修改删除。
6. 点右上角 × 或再次点规划单入口关闭。
7. 切换顶部模块标签不会关闭抽屉。
8. 新建会话时规划单清空。

## 11. 风险审查清单

常驻左侧，不需要勾选，也不需要提交，纯自我反思。五项固定内容：

- 信息真实性
- 研究逻辑一致性
- 独立理解
- 批判性判断
- 成果归属

当 AI 生成参考草稿时，整块会闪 2 秒浅砖红色，提醒你核查。它不会阻断对话，也不会弹窗。

## 12. 导出会话档案

点顶部「导出会话档案」，浏览器会下载两份文件：

| 文件 | 用途 |
|---|---|
| `siche-<会话id>.html` | 用浏览器直接打开，排版好的过程档案，适合提交 |
| `siche-<会话id>.json` | 原始数据备份，便于程序处理或长期存档 |

包含内容：

1. 会话标题、创建时间、导出时间、工具说明。
2. 完整对话流水：每条标【用户】/【AI】、时间戳、完整原文；AI 消息带 content_type。
3. 研究规划单四个栏目；全空会写「本会话未填写规划单」，单栏为空写「暂无填写内容」。
4. 复制与微测试事件日志：时间、AI 消息摘要、content_type、是否触发微测试、微测试题目、你的完整作答、解锁结果。
5. 全局备注：只记录界面复制按钮，手动选中/截图不记录。
6. 完整风险审查清单原文。

HTML 里「复制与微测试日志」默认折叠，点一下展开；对话记录默认展开。

导出文件不包含 API Key、后端配置等敏感信息。

## 13. 数据保存在哪

- 会话、消息、规划单、微测试作答：项目根目录 `siche.db`（SQLite）。
- 绿色版：exe 同目录的 `siche.db`。
- 浏览器 localStorage 只缓存最近会话 id，刷新或重新打开会自动恢复。
- 点「新任务」会新建会话；旧会话仍在数据库里，但当前界面不再显示。

## 14. 常见问题

**发送按钮是灰的？**
- 还没填 DeepSeek 密钥；看顶部是否显示「未配置密钥」。
- 输入框是空的。
- 上一条消息还在分析中。

**顶部显示「未配置密钥」？**
- 在项目根目录（或绿色版 exe 同目录）把 `.env.example` 复制为 `.env`。
- 填 `SICHE_DEEPSEEK_API_KEY=sk-...`。
- 重启服务。

**发消息报错 502 / 503？**
- 503：没有密钥。
- 502：DeepSeek 超时或接口报错；检查网络/额度，稍后重试。输入框内容不会丢。

**点了复制还是没解锁？**
- 微测试不足 80 字或超过 300 字。
- 没有点「提交辨析并申请解锁」。
- 已经点了「暂不测试，保持锁定」。

**规划单预填充没有内容？**
- 你还没有在协作区发过言。
- 或者发言里没有可提取的问题、证据、疑点、下一步。

**导出只下载了一个文件？**
- 浏览器可能拦截了连续下载；在地址栏右侧允许本站「下载多个文件」，再点一次导出。

**消息列表不自动滚到底？**
- 你手动向上翻看历史时会暂停自动滚动；滚回底部后恢复。

**绿色版双击没反应？**
- 是否只拿了 exe，没有解压整个文件夹？
- 是否被 Windows 安全提示拦下？点「更多信息 → 仍要运行」。
- 看同目录 `siche.log` 是否有错误。

## 16. 边界与注意

- 微测试不评分，只做低负荷反思；导出后由老师评估。
- 复制锁定只限制应用内一键复制；截图、手动选中无法物理阻止，也不记入日志。
- 文献线索一律标【待核验】；DeepSeek API 不带联网搜索，不承诺实时网页来源。
- AI 输出严格禁止 Markdown 符号，只用【】标题、换行和空行。
- 本工具不替代教师评价，也不应用来规避学校的生成式 AI 使用规范。
